\# Library Management System



\## Përshkrimi

Aplikacion për menaxhimin e librave në një bibliotekë. Zëvendëson evidencën manuale
(fletore/Excel), e cila shkakton gabime, libra të humbur dhe vështirësi në gjetjen e informacionit.



\## Qëllimi kryesor

Të mundësojë regjistrimin e librave, huazimin dhe kthimin e tyre në mënyrë të shpejtë dhe të saktë.



\## Funksionalitetet (faza e parë, me TDD)

1\. Shtimi i librit (validim i ISBN-së, titullit dhe duplikateve)

2\. Huazimi i librit

3\. Kthimi i librit



\## Teknologjitë

\- Java 17

\- Maven

\- JUnit 5

\- Git \& GitHub
